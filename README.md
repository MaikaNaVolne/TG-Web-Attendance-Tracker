# TG-Web-Attendance-Tracker 🕒

Легкий и мощный инструмент для HR-менеджеров и руководителей отделов. Скрипт позволяет мгновенно собрать отчет по рабочему времени сотрудников прямо из чата **Telegram Web (версии A и K)** без использования API, ботов и сложных выгрузок JSON.

## 🚀 Почему это эффективно?
*   **Time-to-Insight:** Получение готовой таблицы за 1 минуту вместо 10 минут при стандартном экспорте.
*   **Human Factor Support:** Скрипт придает приоритет времени, написанному сотрудником в тексте («Пришел в 08:40»), игнорируя задержки отправки фото.
*   **Zero Infrastructure:** Не нужен сервер или база данных — всё работает в консоли вашего браузера.

## 🛠 Функционал
- **Умная агрегация:** Берет самый ранний «приход» и самый поздний «уход» за день.
- **Детектор переработок:** Автоматически помечает знаком `!` смены, закрытые после 21:00.
- **Игнорирование мусора:** Настраиваемый список (`ignoreList`) для исключения ботов или системных аккаунтов.
- **Поддержка динамического DOM:** Скрипт-аккумулятор собирает данные в режиме реального времени при скроллинге чата.

## 📖 Как пользоваться

1.  Откройте нужный чат в [Telegram Web](https://web.telegram.org/).
2.  Нажмите `F12` и перейдите во вкладку **Console**.
3.  Скопируйте и вставьте код соответствующего скрипта (папка `/version-A` или `/version-K`).
4.  **Медленно листайте чат вверх** от текущего момента до начала рабочей недели (понедельника).
5.  Когда дойдете до нужной даты, введите в консоли команду:
    ```javascript
    stop()
    ```
6.  Получите итоговую таблицу в удобном формате `console.table`.

## 📂 Структура репозитория
*   `/version-K` — Скрипт для обновленного интерфейса Telegram Web K (динамическая очистка имен и привязка к Peer ID).
*   `/version-A` — Скрипт для версии Telegram Web A.

## ⚠️ Важно
Скрипт разработан для запуска в конце недели (например, в воскресенье). Он автоматически вычисляет дату последнего понедельника и собирает данные только за актуальный период.
